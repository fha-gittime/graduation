# graduation
My graduation project :D

# What's it about
A website that you can put an audio file of someone talking (in a language available) and it will translate it for you! You can also use your voice from your device's speaker.

Sebuah situs web yang Anda bisa menaruh sebuah file audio berisi seseorang berbicara (dalam bahasa yang tersedia) dan akan ditransliterasikan untukmu! Anda juga bisa menggunakan suaramu dari speakernya perangkatmu.

# Why?
So users can try to understand what they're saying without trying to follow their voices.

Jadi pengguna bisa mencoba untuk memahami apa yang mereka bicarakan tanpa mencoba untuk mengikuti suara mereka.
